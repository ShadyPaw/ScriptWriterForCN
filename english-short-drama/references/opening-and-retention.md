# 3—5秒开场、钩子与留存

这是本项目的明确创作方向：开头约3—5秒内让观众注意到一个可理解的异常、冲突、选择或情绪问题，并愿意继续看。它不是对所有平台观众的研究结论；效果需用实际观看数据校准。默认仍面向北美英语观众，具体地区/类型/发行方式服从项目卡。

## 三个观看入口

| 入口 | 首要任务 | 后续必须完成 |
|---|---|---|
| 全剧首集 | 在3—5秒内出现具体注意点；让首次观看者识别眼前在争夺什么 | 紧接着补足理解该冲突必需的关系和代价，兑现题材与标题承诺 |
| 后续集开头 | 在3—5秒内接住上集变化或呈现新后果，让人迅速回到当前目标 | 承接原钩子，给阶段答案，避免整集重放或重新解释全部身世 |
| 宣传/信息流片段 | 对独立进入的观众提供足够关系和利益信息 | 区分宣传重剪与正式首集；截取段落不能冒充原剧开场或实际集界 |

秒数从观众看到剧情内容首帧估起；若实际发行有片头、标识或空镜，另记真实等待时间。剧本上的秒数是动作/试读估时，只有实际表演或成片计时才能写成实测。

## 先写一个看得懂的问题

以一个明确动作、物件、反应或可快速理解的台词开始。强冲突可以来自当面利益碰撞，也可以是信息矛盾、不可逆选择、亲密关系失衡或迫近的损失；不要求每集打斗、尖叫或堆灾难。

可选手法及判断：

| 手法 | 有效信息 | 常见失败 |
|---|---|---|
| 当场阻断 | 谁想做什么、谁正在阻止 | 只听见争吵，听不懂在争什么 |
| 事实矛盾 | 观众能辨认的两项信息无法同时成立 | 连续抛专有名词和身份，关系尚不清楚 |
| 选择/代价 | 一个具体动作马上改变人物处境 | 先讲很久背景，选择迟迟不发生 |
| 情绪反应 | 一个对象与反应建立清晰情感问题 | 只有流泪、震惊表情，没有触发对象 |
| 未完成动作 | 观众明白即将发生什么及为何在乎 | 刻意切黑或“你猜”式阻断，后续不给回应 |

原创例：开场是咖啡店老板把“出售”牌翻到背面，门外收购方已举起相同钥匙。它在画面中提出“她还能决定这间店吗”；马上补一句有对象的拒绝或具体期限，比长篇家族介绍更容易建立当前争夺。钥匙代表什么、收购是否完成都需要后续真实机制，不可靠画面误导自动取得产权。

## 开场卡与备选

开发首集或重写问题开头时，按需做两种真正不同的入口，例如“当面对抗”与“证据矛盾”；选择一版继续正文，不让作者为每集逐个审批。

```text
版本 / 集场 / 观看入口：
0—3秒动作或首句（估时）：
至3—5秒观众能理解的事实与问题：
谁受影响、可能失去什么（何时补足）：
下一段推进/阶段回报：
必要信息补足 / 首次回报的位置与动作：
集尾承诺 / 下集兑现位置：
与作者口味、题材、制作条件的匹配：
试读/实测/仅文本估时；待测试点：
```

中文开发稿先确定动作、信息与节奏，英文重写后重新计时；中文一句短话不保证英文也能在同样秒数内说完。若3—5秒塞不下，先让画面或一句行动性台词承担核心问题，再补背景，不加快到演员说不清。

## 从注意点接到第一次回报

把开场、紧接着的一段和首次回报作为同一条因果链设计。这里没有统一的第二个秒数门槛：长度服从本集预算、表演与信息量。

| 段落 | 让观众得到什么 | 正文中的完成证据 |
|---|---|---|
| 开场注意点 | 眼前有哪一项异常、争夺或选择 | 一个可辨认的动作/对象及冲突；不必同时交代全部人物关系 |
| 紧接着的行动 | 谁在争取什么、为什么此刻有后果 | 只补理解当前行动必需的信息；人物随即尝试解决开场问题 |
| 第一次回报 | 一个问题得到部分或完整回答，或一次选择确实改变条件 | 观众能说出新知道了什么、谁得失了什么；不是仅换一个更大问题 |
| 再推进 | 回报带来什么新阻力或关系风险 | 下一行动由已发生结果引起，延续到集尾及下集 |

例如“她撕下自己的婚礼名牌”吸睛后，接十句身世介绍会失去当前争夺。可先让伴侣追问她是否要离开，她要求公开一件已经查实的事；对方选择承认、拒绝或设条件，成为首个可见回报。具体事实、人物底线和终局仍由项目决定，不套用成必写的婚礼冲突。

正文完成后顺读这四段：若开头提出的事在后文消失，补承接或换入口；若信息交代很清楚但人物一直不行动，改阻碍与选择；若回报取消了此前全部后果，重写它产生的新条件。类型案例见 [开场与整场对白练习](examples/scene-lab.md#三种开场的承接练习)。

## 区分好奇与没看懂

对首集或存在理解问题的开场，先写一句“观众此刻应理解的事实”，另写一句“有意暂留的问题”。例如应理解“她拒绝交出文件”，暂留“她为何害怕文件被打开”。若连谁在拒绝什么都不清楚，属于理解障碍；若只能靠后续身世才能明白眼前动作，补当前线索。

有真实读者/观众时，先让其看未附解释的当前片段，再问“刚才发生什么”“你想知道什么”“哪个词或动作不清楚”，记录原回答、位置与版本；先收自由回答，再追问，避免把预期答案提示给对方。文本读稿只验证读稿理解，不等于成片观看。AI自审或不同角色视角模拟均标模拟，没有真人参与则保留待测。

修稿按误解来源选择：对象不明就补动作/称呼，信息堆积就调整释放顺序，看懂但不关心则补利益和选择。只在出现同一具体误解时针对性重测；不用无依据的总分宣称留存通过。

## 留存来自承诺与回报的连续关系

使用 [单集推进](episode-craft.md) 的悬念台账：开场问题进入本集行动，本集有所得/所失，集尾提出由该结果产生的新问题，下集实际回应。信息钩子、关系钩子、行动钩子和情绪悬停可交替；不能靠不断打断一句话、重复误会或推迟同一次身份揭晓拉长。

检查每个吸睛元素有没有后果：若删掉开头冲突后正文完全不变，可能只是噱头。倒叙或预闪可以使用，但标清与真实时间线的关系并按承诺回到它；不把宣传桥段当正片已兑现。

强化开场若新增截止时间、资源条件或道具，立即回查后续台词、时间线、成本前提与兑现，不能只改开头。例如新增“下午五点前保价”，后文仍说“今晚确认”时需明确不同期限或同步修正；不能靠过期条件完成后续胜利。

## 怎么判断该改哪里

无数据时只给“为什么可能吸引/可能流失”的假设。取得真实反馈或数据后分开记录：版本、入口/渠道、样本、观看情境、时间点与分母、开头继续看、单集完播、进入下一集。不同长度、不同剪辑和不同投放来源不能直接当同条件比较。

- 开头掉落：先查期待是否匹配、信息是否可懂、当下代价是否成立。
- 看懂但不关心：查人物利益、选择和情绪承诺，不能只缩短句子。
- 中段掉落：查重复信息、无后果行动、延迟回报或认知负担。
- 集尾停看：查阶段回报是否满足、下一问题是否具体、前几次承诺是否失信。

A/B稿只改变要检验的关键入口，保留项目其它条件并记录差异；未真实发布或试读时称“备选稿/测试设计”，不能编造留存提升。正文输出不自动包含投放运营计划。

方法来源及广告/短剧证据的边界见 [公开资料索引](public-sources.md)。公开观看量可证明特定页面的触达信号，不能直接证明某个钩子导致走红。
