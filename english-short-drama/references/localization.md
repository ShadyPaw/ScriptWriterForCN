# 本土化改编

用于已有中文故事、梗概或剧本的英文改编。英文原创也可用末尾核查，但不必制作逐条中英对照。

## 改编前锁定

确认可使用的素材和权利范围、目标英语受众、不可改的主题/人物关系/核心反转、可改的地点/制度/事件、可接受的改动程度。权利未清不把换名换地视为取得授权；可继续分析问题与独立原创方向。

区分三种任务：直译供理解、忠实英语改编、为新市场重构。用户要求忠实版本时先保存原机制，再指出哪里需要另做本土化方案，不能未经说明重写主题和结局。

## 保留功能，重建因果

对关键桥段写清“原事件 → 戏剧功能 → 当地机制 → 角色动机 → 铺垫 → 后果 → 需核事实”。判断标准是新场景能否独立成立，而不是中文名全部替换成英文名。

可考虑的转换方向，均需结合项目验证：

| 原冲突机制 | 先保留的功能 | 可探索的改写 |
|---|---|---|
| 家族长辈一句话决定一切 | 资源控制、归属压力、情感债 | 具体家族企业决策权、家庭支持条件或照护责任；涉及财产权另核验 |
| 因礼俗受公开羞辱 | 群体评价与自我价值受损 | 当地社群/学校/工作场合有动机的公开冲突；不机械搬入宴会 |
| 医院即时要求神奇巨款 | 紧迫损失与艰难选择 | 研究当地真实费用/照护机制，或另选确实有期限的生活危机 |
| 全员反复称“少爷/总裁” | 身份差距与权力距离 | 根据职业、关系与场景重写称呼；保留确有文化背景的用法 |
| 契约关系让人物无法退出 | 依赖、秘密、声誉或利益绑定 | 建立具体选择代价；协议不是万能合法强制工具 |

不是每个中国文化元素都需要替换。华裔家庭或跨文化故事可以保留真实生活逻辑，并让英语观众通过行动与关系理解。不要默认本土化意味着白人化。

## 五层改编检查

1. 概念层：目标受众能迅速理解关系和风险，卖点仍然成立。
2. 机制层：引发冲突的制度/习俗有当地依据，改变机制后的前因后果完整。
3. 人物层：欲望、边界、身份和关系自洽，不因换地突然改变价值观。
4. 场景层：信息通过冲突与行为表达；改动影响的伏笔、道具、时间线一起重写。
5. 语言层：重写口语、笑点、隐喻和称谓，再核验专有名词、单位与拼写。

交付本土化决策与当前语言的新稿：默认中文开发供编剧修改，回传后执行 [英文重写](chinese-to-english.md)。仅对关键改动给中文理由，不默认逐句双语并排。英文再回查中文可帮助核对信息，但不能证明英文自然或当地文化准确。

需要从机制调整一路落实到新对白和前后回收时，读 [完整本土化案例](worked-example.md)。对照项用于说明取舍，最终只交付用户选定风格的正文。
