# 文化背景与当地事实

选定真实可研究的城市/州/省或明确的虚构城市，并写明借用哪套现实制度；类型化幻想世界则建立自洽规则。高戏剧性可以夸张情绪，决定人物能否行动的事实不能凭印象拼接。

## 世界设定最小集

| 维度 | 对剧情有用的记录 |
|---|---|
| 地域与年代 | 城市规模、交通和距离、气候、生活场所、时代技术 |
| 生计 | 职业日常、班次、收入压力、住房与照护责任；不无依据写具体统计 |
| 社会关系 | 家庭边界、亲密关系、朋友/宗教/社群支持、权力来源 |
| 人物身份 | 个人经历、语言、移民代际或地域经历；只保留影响选择的细节 |
| 制度 | 剧情涉及的学校、医疗、雇佣、司法、警务、财产或婚姻程序 |
| 物件与语言 | 币种、单位、日期格式、手机界面、地名与称呼词表 |

美国与加拿大、各州/省不是可互换的背景。身份、健康、婚姻和职场冲突也不是所有北美人的共同经验。需要事实时从相关政府/法院/学校/医院等一手来源核实，不用别的影视桥段作为制度证据。

## 事实台账

记录：事实ID、剧中断言、影响的集场、地点/年代、来源、检索日期、状态（已核实/合理虚构/待核实）、修改方案。优先核实会改变故事因果的事实；普通装饰细节无需写成长报告。

来源、虚构及待核状态写在稿外记录。正文通过当事人提出的条件、他人的回应和实际后果建立私人规则，例如“到期人数不够就取消”。角色不必替作者声明“这不是某城市/行业的统一规定”；只有人物当下确实在争论规则适用范围时，才把这种区别写进对话。

典型核验触发：医疗费或保险驱动主线；一纸协议立即改变监护/继承；老板当场改变他人法律身份；警察/法庭即时处理复杂案件；跨境旅行、枪支、酒类或婚姻年龄影响转折。这些是研究提示，不是预设违法结论。

无法确认时选一种处理：改成不依赖该程序的私人冲突；减少具体制度断言并保留合理过程；标待当地专业核验。不能以“虚构作品”解释明显破坏因果的制度混用。

## 文化阅读

检查人物为什么在这个社群做这个选择、别人为什么接受或反对、代价怎样落在日常生活。节日/食物/地标应有戏剧用途，不能承担全部本土感。少数群体角色有个人欲望与矛盾，反派行为不代表群体本质；创作可以呈现偏见，检查作品如何建立视角与后果。

特殊社群、强方言、创伤经历或真实历史成为核心时标出需要当地读者/顾问反馈的具体问题；没有反馈不能写“文化审核通过”。不自动联系任何人。

向实际参与的当地读者提问：哪项行为在这个具体家庭/行业成立或不成立，依据是什么？哪句英语体现了人物而哪句像译文？哪条制度断言改变了人物选择？哪个道具/称呼/反应需要额外解释？记录其经验范围、具体位置和修改建议；个人经验与可核实规则分开，不把一个读者当整个北美受众。
