# 白皮书创作执行规则（北美英语适配）

首要创作原则来源：作者提供的短剧编剧白皮书创作内容。本技能保留适用于北美英语短剧的操作清单，不收录原文；需要逐段核对时由作者查验本地原件。W编号为本技能的核查编号。

## 采用与核查

| 编号 | 要执行的判断 | 合格证据 |
|---|---|---|---|
| W01 | 用一个明确问题统领主线，激励事件改变原有处境 | 一句话故事、前后处境、最终回答 |
| W02 | 按媒介重新设计结构，模型服务故事 | 所选模型、关键转折及调整理由 |
| W03 | 主角有具体Want、内在Need和承担代价的选择 | 起点、至少一个关键选择、后果与终点；平弧要有信念考验 |
| W04 | 人物小传回答伤口、恐惧、隐秘渴望、价值冲突、极端选择、声音与起点 | 小传和正文行为相互支持，配角有自身动机 |
| W05 | 角色可被表演，有身体习惯、秘密与经铺垫的高光 | 具体动作和关系，不以形容词替代表演 |
| W06 | 对白是人物为达目的采取的言语行动 | 说话目的、策略变化、回应或回避，信息自然进入冲突 |
| W07 | 人物声音有辨识度，潜文本与直白信息各有用途 | 遮名试读、朗读；删除套话、解释腔、说教与统一腔调 |
| W08 | 每场聚焦一项核心变化，同时服务情节、人物和张力 | “从什么变成什么”；删除该场会损失什么 |
| W09 | 场景尽晚进入、功能完成后退出；时长用表演检验 | 台词朗读、动作、停顿和反应时间分开估计 |
| W10 | 冲突源于人物目标与价值碰撞，争吵存在策略和权力变化 | 欲望、阻碍、为什么此刻发生、不可逆后果 |
| W11 | 钩子让观众明白在等待什么，牵涉人物和损失 | 钩子问题、代价、预计回应集及实际回收 |
| W12 | 张弛相间，高潮有细节、关系或对比积累 | 高潮所依赖的前置场次，缓冲戏也有功能 |
| W13 | 转折可回溯到人物、关系和主题，强情绪不依赖任意巧合 | 因果链；提前设置的信息和选择 |
| W14 | 改编核查素材权利和事实，内心活动转化为视听行动 | 授权/权利状态、事实与虚构区分、核心改编取舍 |
| W15 | 视角有明确的信息边界与情感距离 | 每场观众与角色分别知道什么，信息从何获得 |
| W16 | 先设计终场，再倒推伏笔；结尾用行动兑现主题 | 开场与终场呼应、核心问题解决、意象有建立/加深/转化 |
| W17 | 修稿回查因果、人物、场景，并换位检验 | 逆序阅读、配角视角重读、口述或模拟口述的问题清单 |
| W18 | 剧名好记、气质匹配、具辨识度且与内容相符 | 候选标题及筛选依据、标题合规初筛 |
| W19 | 设计可拍的场景，目标—失败—风险循环带来质变 | 场地/人物/道具清单；每次失败改变行动条件或价值代价 |
| W20 | 短剧快速建立人设、拆分信息、设计追更节点 | 前三集能看懂关系与目标；分集推进和阶段回报明确 |
| W21 | 正文是可供剧组执行的视听蓝图 | 场景标题清楚、动作可见可听、台词与说明分开 |
| W22 | AI辅助构思与修订，人类编剧控制独特经验与最终表达 | 编剧意见、处理记录、未经过真人反馈的状态诚实标注 |

对适用条目逐项写“通过/需改/待核验/不适用”，给出集场定位；不适用要有原因。“整体符合”不能代替检查。

## 跨媒介与冲突处理

1. 白皮书目录及前言模块数量不一致，以实际章节标题为准；不能据“前十模块”漏掉§11短剧创作和§12视听语言。
2. §1的25%/50%/25%、电影110页、15分钟分段是结构参照，不能直接套成北美短剧集数、英文词数或平台规则。先按总时长和实际剧情映射，再提前安排短剧的激励事件。
3. §4的“一场三功能”和“一场一任务”统一为：一项核心变化，可兼有三种功能。关系铺垫和喘息戏可以通过改变理解与预期推进故事，不必每场新增事件。
4. §11主要来自付费短剧经验。北美项目先确认目标平台及当次分发模式，用追看、完播和情绪兑现设计节点；不默认每10集付费、不默认80—100集、不捏造先交十集的官方要求。后台数据仅使用实际提供的数据，不推断私有完播率或收入。
5. §11强人设与§2人物深度共同执行：出场识别快，后续选择仍需因果和真实代价。身份揭晓不等于人物成长，也不能凭标签替代弧光。
6. §3“删掉真心话”是潜文本练习，适用于有遮掩动机的场景；求救、指令、关键告白等有充分动机的直白表达可保留。阶层/地域/职业不能机械决定语言或品德；语言失稳不是可靠的测谎结论。
7. §6“先版权、再改编”作为本技能的素材管理要求；权利不清时先做权利澄清与独立原创替代方案。是否依法需要许可、合理使用或公版等具体结论按现行法核实，不把白皮书经验当法条。
8. §8冷处理三天至一周是人类写作建议。当前任务先用逆读、换视角等完成修改；仅在用户要求时安排日后复审，不为了冷处理停止已授权工作。
9. §8意象三次使用先按“建立—加深—转化”设计；极短体量需要合并时记录取舍。镜像是功能呼应，不必机械重复同地点。悲剧和开放结尾依用户约定，但核心承诺需有回应。
10. §9“五字以内”等命名经验不是行业硬规范；以准确、记忆度、原创性及有效审核规则为准。§10/12舞台3—4场景、每场3—5分钟、一人分饰等只用于实际舞台/学生短片条件，不强加于竖屏短剧。
11. 原文中的科学、史实、名言归属及产品能力并非已核实事实；创作无需复述这些背书。如用户要求论证，另行查证。
12. §14商业条款全部排除；编剧署名、版权及内容核查仅保留与创作和合规直接有关的部分。

## 英文项目适配边界

白皮书是首要创作原则来源，不是北美平台、法律、对白习惯或英文排版规范。W07用英文角色声音与当地语境核查；W14按实际权利与法域核查；W18不采用中文标题字数限制；W20按实际分发模式安排追看与回报；W21按英文剧本模板执行。具体要求见[对白](dialogue.md)、[本土化](localization.md)、[格式篇幅](format-and-length.md)及[北美初筛](north-america-compliance.md)。
