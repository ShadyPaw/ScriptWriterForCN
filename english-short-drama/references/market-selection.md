# 选材与市场证据

## 先定义选材对象

明确目标平台、国家、语言、受众和变现/分发方式。付费解锁、广告支持和开放社交分发的节点需求分别设计；没有实际简报时不固定第几集设付费卡点。英语作品不一定是美国作品；中国热度不能直接当北美热度。

## 每次选材刷新

从当日向前查看近30天，再视证据量扩展至90天；这只是研究窗口，不是行业硬规则。记录内容发布日期、实际榜期/观察日期、访问日期及地域。老报告只供背景，不写成“当前趋势”。

优先使用平台官方榜单、官方目录/上线信息、制作方公开资料和可核实的第一方项目数据。第三方报告用于补足覆盖，标清方法和局限。入口包括 [ReelShort 英文目录](https://www.reelshort.com/en)、[DramaBox 目录](https://www.dramabox.com/browse/201)。2026-10-14 检索可见目录片段，但直接访问部分页面返回403；这些入口不构成已核实的北美实时榜单。

证据按实际可证明范围表述：

| 观察 | 可以说 | 不能推出 |
|---|---|---|
| 官方明确地区、时间和指标的排行 | 该榜期该地区在该指标上的位置 | 未公开的盈利、留存、转化 |
| 首页 Trending/推荐卡片 | 本次可见页面重点展示 | 北美用户共同偏好、自然排名、票房 |
| 分类页和作品数 | 平台有该类型供给 | 正在增长、当前最热、竞争小 |
| 社交播放和评论 | 该内容在该账户的可见互动 | 付费意愿、完整剧情完播、全市场规模 |
| 发行方收入披露 | 披露口径内的项目/公司表现 | 单剧收入、净利或其它地区表现 |

无法联网/登录/确定地区时明确数据缺口，仍可给标为“待验证”的选材假设；不编造榜单或强行凑来源数量。保留实质不同的平台或数据来源，避免把转载同一报道当多重证据。研究热门作品仅分析类型承诺、结构与供需，不复刻其独特人物组合、连续桥段和台词。

## 候选的七个判断

1. 观众承诺：谁会为什么情绪留下，首集如何让人看懂。
2. 戏剧引擎：主角反复追求什么，每次失败怎样改变条件；靠一次身份揭晓能否支撑整季。
3. 类型兑现：浪漫关系的选择、悬疑的线索、公平回报或家庭抉择实际出现在哪些场景。
4. 差异化：职业、关系、目标、价值冲突或视角至少有具体新组合，不只换名字。
5. 当地可信度：这个冲突在选定城市/社群为何成立，需要核实哪些制度。
6. 可拍性：常驻场景、演员数量、群演/动物/夜戏/视效等约束。
7. 风险和证据：原创/改编权利、敏感内容处理、趋势证据范围及反例。

可以探索浪漫、家庭、职场、复仇、悬疑、成长、超自然等候选，但它们是题材池，不是永久热榜。不要把女性观众等同某一种类型，或把北美等同白人、富人、异性恋。

## 选题卡

每项输出当前语言的工作剧名与一句话故事、中文核心情绪、目标细分受众、前三集可发生的冲突、阶段升级机制、结尾承诺、最小可行制作条件、主要风险、证据链接/日期/地域/指标、推荐/保留/淘汰理由；英文logline按交付语言或用户需要提供。可持续性按 [故事发展](story-development.md) 检查人物计划如何不断改变条件。若用评分，权重来自本项目取舍，缺数据标未知，不把总分伪装成市场成功概率。

最终给出明确推荐和次选，并写出什么新证据会改变推荐。

## 实际平台需求卡

用于已有平台/委托对象或需要准备提案时；通用开发只填写影响当前写作的字段。

| 字段 | 记录内容 |
|---|---|
| 对象与用途 | 国家/英语变体、平台或具体项目；完整独立作品、试播/开发样片或写作样本 |
| 分发 | 专门App、社交信息流或其它；免费/广告/付费信息的依据；实际要求的节点 |
| 创作边界 | 受众与内容尺度、基调、题材、角色/场地限制；区分用户选择与平台要求 |
| 文件 | 实际模板及版本/取得日期、集标题/场号/文件格式、N/W/时长、需要提交的材料及范围 |
| AI与来源 | 实际委托条款对AI辅助、披露、来源记录、保密素材输入的要求；未知则标未知 |
| 证据状态 | 用户提供简报/官方公开要求/沟通记录/待核；链接或文件位置、日期、适用项目 |

只依据实际取得的文件准备提交材料，不默认先写十集或把写作样本等同整剧。需求有冲突时记录版本和适用范围；平台目录页不是委托简报。教学课销售页也不能证明平台认可某套模板。相关公开实例见 [资料索引](public-sources.md)。

## 作品拆解如何回到选材

对可合法访问的样本记录实际观看集/时段及来源；只读简介就只分析简介，不编造观剧记录。依次提取受众承诺、主人公目标、对抗机制、首个不可逆选择、连续三集条件变化、阶段兑现、可拍资源。将“屏幕上发生了什么”与“我推测为什么有效”分列。

用 [原创案例](worked-example.md) 演示这一拆法；它没有上线或观众数据。[平台样本与分析卡](platform-cases.md) 收录有公开热度信号的历史作品、前段梗概分析和近期推荐核查，逐项标材料范围。实际选材仍刷新当次证据，不能把旧热门、简介解读或练习当当前观剧/留存数据。
