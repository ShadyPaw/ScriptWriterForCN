# 中国内容合规初筛

用于剧本创作风险识别和改写，不代替主管部门、播出平台或专业法务的审查。检查时说明适用地域、作品形态和是否计划公开发布。根据情节所涉实际风险核查，避免给普通创作添加无关手续。

## 先核实时效与效力

选材时初查，定稿时复查。通过全国人大/国家法律法规数据库、国家广电总局、国家网信办、国家版权局等官方渠道确认现行文本；平台要求从可验证的官方规则取得。记录名称、制定机关、文号（如有）、发布日期、生效日期、修订状态、具体条款、链接和查询日。

**法律、行政法规、部门规章、管理通知、行业倡议、平台规则、征求意见稿分别标识。** 征求意见稿不当成已生效规则。若只能获取旧版本或二手报道，写待核验，不给确定性法律结论。不要凭记忆沿用旧投资分档或将平台偏好称作国家禁令。

## 从剧情出发检查

下列是编剧检查问题，不是逐字法条，更不意味着相关题材一律禁止。判断须结合表现方式、叙事立场、镜头细节、目标观众及有效依据。

| 风险面 | 逐场核查问题 | 常用修订方向 |
|---|---|---|
| 国家、历史、民族宗教、特殊题材 | 地图、标识、称谓、史实与人物定位是否有依据？是否涉及需另核的题材程序？ | 查真实资料；减少无依据的指控、符号与事实替换；必要时提出具体待专业核验项 |
| 未成年人 | 是否色情化未成年人、消费儿童受害、诱导危险模仿或强化欺凌？ | 从保护和后果组织情节，移除色情化/可模仿细节，保留必要的非露骨冲突表达 |
| 亲密关系与歧视 | 作品是否把胁迫、控制、性暴力或人格羞辱包装成值得效仿的爱情？ | 给角色真实意愿和边界，展示行为后果与责任；不靠性别/地域/身份贬损制造快感 |
| 犯罪、暴力、自伤 | 是否把具体方法变成教学、把暴力报复塑造为唯一奖励？ | 保留悬念、损失和选择，压缩操作细节，重写翻盘机制和责任后果 |
| 财富与价值表达 | 是否仅以财富等级衡量人的尊严，持续炫富拜金或激化群体对立？ | 让能力、劳动、互助、诚实选择承载回报；富人、逆袭或争产题材本身不自动判违规 |
| 迷信、奇幻 | 架空规则是否被包装为现实有效的算命、驱邪、治疗或骗财方法？ | 保持虚构边界，移除现实诱导；重生、奇幻不凭标签一刀切 |
| 真人、专业领域 | 是否可识别真实个人并捏造其过错、泄露私密信息？医疗、司法等情节是否误导？ | 分清公开事实、虚构和推测；真实事件做权利/事实核验，相关专业情节用可靠资料修正 |
| 著作权 | IP、桥段、台词、歌词、图片、商标使用是否有权利基础？ | 区分公共思想与受保护表达，保留来源/授权清单；实质性改编缺少权利依据时提供独立原创方案 |
| 剧名与宣发 | 剧名、梗概和预告语是否低俗、误导、与正文不符？ | 标题随正文一起核查，不用标题规避正文标准 |
| AI制作与传播 | 实际使用何种AI生成内容？哪些主体、环节和标识要求适用？ | 记录实际使用情况与当前规则；纯辅助创作不凭猜测宣称已免除或已完成所有标识义务 |

负面行为的描写与宣扬需要结合上下文判断；不能通过片尾一句“坏人受罚”自动消除前文风险，也不必把所有反派台词当成作者立场。对灰区给出保留戏剧功能的两种替代方案及取舍。

## 审查记录与结论

每项记录：`编号｜集-场/原句｜事实描述｜风险性质（法律/行政/平台/创作伦理）｜有效依据及条款｜判断理由｜具体替换方案｜处理状态｜复核版本`。

分级为：实质问题需修改、存在解释/材料缺口待核验、建议优化、未发现问题。找不到依据的个人偏好只能列为创作建议，不能伪装成违法结论。只问与实际风险有关的缺失材料。

使用结论：“本次创作合规初筛基于____日期核实的____及版本____；范围____；结论____；待核事项____。”实质问题或关键规则未核实前不标合规通过。书面授权的真实性、最终成片、平台审核和法定播出程序不能由剧本阅读确认。
