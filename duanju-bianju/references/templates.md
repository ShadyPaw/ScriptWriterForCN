# 工作模板

按当前阶段使用相应模板，不要求一次输出所有表格。具体正文另见 [格式约定](format-and-length.md)。

## 项目约定

```text
项目名 / 当前版本 / 当前阶段：
已确认事项及对应用户消息：
受众 / 核心情绪体验 / 主题命题：
目标平台 / 真人或动画 / 竖屏或横屏：
原创或改编 / 素材权利状态：
题材与禁区 / 必须保留的表达：
总集数 / 单集时长范围：
总正文目标 / 统计口径 / 容差或硬上下限：
每集预算 / 拍摄资源约束：
结局类型 / 主角弧光 / 主要结构模型：
交付格式与批次 / 是否授权代选与自主修改：
待确认事项 / 下一步：
```

## 人物小传与场景卡

小传：角色身份与年龄范围、外部目标、深层需要、伤口/恐惧/隐秘愿望、相冲的价值观、保护性行为、压力下的选择、秘密、专属说话方式与身体习惯、关系变化、起点与终点。信息要能落实到戏，不写无功能的履历。

场景卡：`集-场｜时间地点｜视角｜双方意图｜核心变化｜阻碍｜行动/反应｜价值或关系前后｜观众/角色信息差｜代价｜铺垫/回收｜预估时长`。

## 分集表

| 集号 | 本集目标与阻力 | 主角选择/代价 | 信息/关系变化 | 情绪回报 | 末尾问题及回应集 | 伏笔/回收 | 目标字数 | 实测字数 |
|---|---|---|---|---|---|---|---|---|

字数目标合计应等于项目总量。另列全剧起点、激励事件、跨阶段选择、中点变化、危机、新方案和终场；节点可合并，不要求机械均分。

## 连续性台账

| 类别 | 已确立事实/伏笔 | 建立集场 | 哪些角色知情及获知途径 | 预计回收 | 当前状态 | 修改影响 |
|---|---|---|---|---|---|---|

覆盖年龄、称谓、日期、地理/出行、重要物件与证据、伤病状态、关系、秘密、规则和未兑现承诺。与正文冲突时先核对编剧已确认版本，不能为了续写方便静默改设定。

## 修改单

| ID | 集场定位 | 问题及影响 | W编号/技法/有效规则 | 具体改动 | 牵连集场 | 状态与复核 |
|---|---|---|---|---|---|---|

先处理会改变主线或人物动机的问题，再润色。对白给必要的前后对照，避免整稿反复展示占篇幅。

## 编剧把控

```text
送审版本 / 已完成修订范围：
主角最终选择与主题是否符合原意：
最需编剧判断的生活经验、人物关系或情绪问题：
待决项A：当前写法 / 方案1 / 方案2 / 各自影响。
必须保留的原创表达与不可改变设定：
编剧意见原意 / 接受或部分接受 / 修改落点：
尚未获得编剧反馈的项目：
```

对用户的“继续”“按推荐改”等指令按明确上下文执行，保留授权记录。用户未说过的评价不能写成“编剧已满意”。

## 定稿核查

1. **交付与篇幅**：目标/实测集数、每集与合计字数、口径、容差、实际运行工具与报告位置。
2. **白皮书**：W01—W22逐项列状态、集场证据、修正或不适用理由。
3. **剧情与连续性**：主线闭合、人物选择、规则一致、关键伏笔回收、跨集接续；指出仍有意保留的开放问题及原因。
4. **编剧反馈**：每条意见的处理结果，尚需其判断的事项。
5. **中国合规初筛**：日期、适用规则、风险位置、修改记录与待核材料；结果不能替代播出审核。
6. **版本**：最终正文文件、版本、实际状态（定稿/待确认/待核验）与剩余事项。
