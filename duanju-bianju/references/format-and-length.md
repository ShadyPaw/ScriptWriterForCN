# 格式、集数与篇幅

采用项目/平台已确认模板；未提供时使用下列中文文学剧本约定。它是本技能的工作格式，不宣称为全国统一标准或红果唯一格式。

## 规范正文

```text
## 第1集 收据
[正文开始]
1-1 日 内 修理铺
人物：林禾、老周
△林禾把湿透的收据铺在柜台上，用玻璃杯压住卷起的边。
林禾：这台收音机，您还记得是谁送来的吗？
老周（没抬头）：修好的东西，我不留姓名。
△林禾翻过收据。背面是一张她小时候的照片。
林禾：那这张呢？
[正文结束]
```

上述为原创格式样例，不是完整集数示范。正式一集可有多场，每场换行注明 `集号-场号 日/夜 内/外/内外 地点`；人物行列出实际出场者。持续时空场景不随便换号。需要时可用晨/昏等明确时段，并在项目约定记录。

动作独立起段，以△标识；台词用`角色名：台词`，必要的小动作括注紧跟人名。`角色名（OS）：`代表同场画外声，`角色名（VO）：`代表旁白/回忆等非同场画外叙述；若平台采用不同含义先统一。短信等用`【屏幕文字】`，闪回写`【闪回开始】`与`【闪回结束】`并明确时间地点。

只写能拍到、听到或演出的内容。时间线、心理解释和镜头设计如确有必要，以清晰可执行方式体现；不默认生成分镜头表。集末钩子在动作或台词中发生，给编剧的钩子说明置于正文标记外。

## 约定字数口径

先确认用户指的是正文还是整个交付包，以及使用何种计数。梗概、小传、核查说明不应为了凑正文目标混进正文。

默认建议“创作净字数”：只统计各集`[正文开始]`与`[正文结束]`内的动作、表演括注、台词和屏幕文字；去掉场景标题、人物行、说话人姓名、动作符号、OS/VO标记、其他格式标记和标点空白。每个汉字计1；连续拉丁字母/数字组合计1；其他语言字母按字符计。该口径由脚本实现，与Word“字数”“字符数”不等同。

另报告正文区原始非空白字符数，方便复核差异；该数含场头、姓名、标点。若约定Word口径，必须用对应文档工具或用户实际Word统计验证；脚本结果只作参考，不能标为Word实测。

用户仅说“总字数”时提出上述默认及容差建议，让其与体量方案一并确认；用户明确“至少/不超过/精确”时严格保留边界。不能默认以±5%覆盖用户硬上限。

## 分配与调整

N为约定集数，W为约定净字数。先计算均值W/N，按普通集、重要对决、终局等需要设置正权重，用最大余数法取整，使ΣWᵢ=W。均值只是检查尺度，不是每集一模一样。

工具在技能目录运行，支持Python 3标准库：

```text
python scripts/script_metrics.py plan --episodes 24 --total 24000 --out budget.json
python scripts/script_metrics.py plan --episodes 4 --total 4200 --weights 1,1,1.2,1 --out budget.json
python scripts/script_metrics.py audit --script full-script.md --episodes 24 --target 24000 --tolerance 0.05 --out metrics.json
```

`--tolerance 0.05`仅在双方同意±5%时使用；默认0。硬下限/上限用`--min-total`、`--max-total`，可与目标同时指定。单集范围用`--min-episode`、`--max-episode`。审稿文件使用UTF-8；多集按序合并到一个正文文件再核验。工具发现集数、正文标记、场次或字数问题以非零状态返回，并保留报告。

审稿时列每集目标、实际、偏差和调整动作。扩写应增加有效选择、冲突或兑现，缩写优先删重复信息与无功能场面；不能复制台词或把“……略”当完成内容。总量偏差分摊回未锁定集，再复算整稿。

## 时长与长篇接续

时长由对白试读、动作、反应、沉默和剪辑共同构成，不能固定“每字等于几秒”。文字估计可给范围，但真正计时前必须标“估计”。若2分钟单集被要求塞进数千字对白，先提交可行性诊断与调整选项。

全本写作保留统一称谓、时间轴、人物知识及伏笔台账，分批只是实现方式。结尾集可增加收束预算。定稿前逐集查序号完整、场号顺序、角色关系、跨集钩子接续和终局兑现。

导出Word时去掉内部正文标记、工作台账与审稿批注，正文和附件分开；保留集场编号、清晰标题、动作与对白分段。核验DOCX文字与通过核查的正文一致，再渲染检查分页、字体和溢出。没有实际导出和渲染就不宣称已验收Word。
